Engineered Features

Built for heavy, multi-hour agent sessions

Designed to withstand complex coding migrations, large codebase reviews, and multi-agent parallelism without losing track of your token budget.

01

Interactive Turn Velocity Graph

Every agent turn is measured in real-time. The 16-step sparkbar graph provides instantaneous visual telemetry of token consumption spikes.

  • In-Graph Header Sync: Hovering any sparkbar updates the exact input and output token count directly inside the header without awkward mouse tooltips.
  • Step Inspector Drawer: Click any sparkbar to open a deep payload breakdown of that exact turn, revealing which tool calls or file chunks caused the spike.
  • Proportional Severity Anchors: Bars highlight elevated (amber) or critical (red) thresholds to warn you of runaway loops.
02

Progressive Payload Attribution

Know where tokens actually live. Instead of an opaque single number, five progressive drawers categorize every token in context:

  • Skills & Instructions: System prompts, workflow definitions, and tool declaration overhead.
  • Code Files: Exact token counts for all source code read and edited in the session.
  • Markdown & Plans: Implementation plans, specs, and conversation artifacts.
  • Terminal & Commands: Shell outputs, compiler errors, and command line dumps.
  • Prompt Cache Warmth: Real-time cache hit rate tracker, elapsed response counter, and warm window timer.
03

Agent Fleet & Subagent Tracking

Modern agentic coding uses swarms of parallel subagents. Context Monitor gives you first-class cockpit visibility into the entire agent tree.

  • Hierarchy Connectors: Real-time tree view linking the Root Orchestrator to background child subagents.
  • Live Execution States: Instant green (RUNNING) and grey (IDLE) status indicators for background processes.
  • Active Tool Surveillance: Displays what command or file operation each subagent is actively executing.
  • Isolated Subagent Contexts: Monitor individual token accumulation before launching new parallel tasks.
Engineered Differently

Zero API tokens. Zero prompt interruptions.

How Context Monitor achieves total out-of-band telemetry without polluting your context window.

1. Local Transcripts & SQLite

Antigravity writes conversation logs directly to disk (`transcript.jsonl` and `conversation_summaries.db`). Context Monitor streams these files using native Node.js zero-dependency file and SQLite readers.

2. Out-of-Band Sidecar

The sidecar runs as an independent daemon. It never injects prompt messages into the agent's turn loop and never consumes LLM inference tokens. Telemetry calculations happen in pure local V8 microsecond routines.

3. Native Side Pane View

The webview docks directly in Antigravity's auxiliary side pane. Telemetry refreshes every 3 seconds with zero flicker, tabular numbers, and surgical contrast designed to match the Antigravity dark theme.
